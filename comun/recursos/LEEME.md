`ccaa.geojson`: contornos de las comunidades autónomas, simplificados (tolerancia 0,03°, coordenadas a 2 decimales, sin islotes muy pequeños).
Origen: proyecto «click_that_hood» de Code for America, `public/data/spain-communities.geojson`
(https://github.com/codeforgermany/click_that_hood), licencia MIT (Copyright (c) 2013-2021 Code for America).
Se ha conservado solo el código de comunidad (`territorio_id` = "C" + código INE).
Canarias está desplazada (+5° de longitud, +7° de latitud) para dibujarla junto a la península, como es habitual en los mapas de España.
